Variables & Data Types

A variable is a name bound to a value. Python figures out the type for you — no need to declare it up front.

  • int, float, str, bool are the core built-in types
  • Use type(x) to check a variable's type at any time
  • Python is dynamically typed — a variable can be reassigned to a different type

Strings & String Methods

Strings are immutable sequences of characters with a rich set of built-in methods.

  • .upper() .lower() .strip() .split() .join() .replace()
  • Slicing: s[start:stop:step]
  • f-strings: f"{name} is {age}" for readable formatting

Lists, Tuples, Dicts & Sets

Python's four core collection types, each with a different job.

  • list — ordered, mutable: [1, 2, 3]
  • tuple — ordered, immutable: (1, 2, 3)
  • dict — key/value pairs: {"a": 1}
  • set — unordered, unique values: {1, 2, 3}

Decorators & Generators

A decorator wraps a function to add behaviour without changing its code. A generator produces values lazily, one at a time, instead of building a whole list in memory.

  • Decorators use the @decorator_name syntax above a function definition
  • yield pauses a function and returns a value, resuming from that point on the next call
  • Generators are memory-efficient for large or infinite sequences

Working with Dates

The built-in datetime module handles dates, times, and the arithmetic between them.

  • datetime(year, month, day) creates a specific date
  • timedelta represents a duration you can add to or subtract from a date
  • .strftime(fmt) formats a date as a readable string
